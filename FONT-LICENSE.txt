What was changed in this copy
-----------------------------
Only the Regular weight is included. It was repackaged from the
OpenType file texgyreschola-regular.otf (version 2.005) into the WOFF
web-font container so a browser can load it. The glyphs, metrics and
font names inside the file were not changed.

The font's authors and GUST do not provide support for this app.
Please report problems with the app to the app's maker.
